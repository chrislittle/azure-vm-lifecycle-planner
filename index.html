VM Lifecycle Planner for Azure

Give this tool your Azure VM list. It shows the lifecycle stage of each VM and the supported v5, v6 and v7 sizes.

A community tool. Not affiliated with or endorsed by Microsoft.

This tool runs only in your browser. It does not upload or keep your list. This page cannot send data over the network. How to make sure that no data leaves your browser

1 Get your VM list

From Azure recommended

  1. In the Azure portal, open Resource Graph Explorer.
  2. Paste this query and select Run query. The query only reads data. It does not change anything.
  3. Select Download as CSV. Then load the file in step 2.
Azure Resource Graph query

        

        
The query lists each VM in the subscriptions that you can see. It gives the facts that this tool needs, for example the size, generation, OS image, NICs, disks, accelerated networking and Azure Disk Encryption.

      

      

        
By hand

        
If you make the list yourself, use the template. Only Machine name, Current size and Generation are necessary. If one of these three columns is empty, the result is "Not checked". If another column is empty, this tool shows "Check:". It does not show an empty column as a pass.

        
Download the template

        
In Excel, select the rows and the header row. Copy them. Paste them in step 2.

      The zip file has three results files and one file about the results. Start with vm-summary.csv.

  • Select a VM to see the reason and the notes for each series. The table shows size names without "Standard_". The details and the download files show the full names.
    • 
      
  • "Supported" means that Azure lets you move this VM to the new size. It does not mean that the VM is ready to move.
    • 
      
  • A move is a resize or a rebuild. In a resize, Azure changes the size of the same VM. In a rebuild, you make a new VM with the same disks. A rebuild removes a system-assigned identity and Azure Disk Encryption.
    • 
      
  • This tool does not check if a size is available in your region.
    • 
      
  • AKS nodes are not in the VM list. To change their size, change the AKS node pool.

Privacy, and how to make sure that no data leaves your browser

    
    
      
  • This tool runs only in your browser. There is no server. GitHub Pages sends the page as plain HTML and JavaScript. Anyone can read the code.
    • 
      
  • A Content-Security-Policy in the page stops all network requests (connect-src 'none'). It also stops scripts from other sites.
    • 
      
  • To make sure: Open the developer tools of your browser (F12). Select the Network tab. Then show the results for a list. The page sends no request.
    • 
      
  • You can also disconnect from the internet after the page opens. The tool continues to work.
    • 
      
  • Your browser makes the results files. The download saves them on your computer. The page does not send them over the network.
